# Keyboard Mappings

## Leader Key
`Space` - Leader key prefix

### General
| Key | Description |
|-----|-------------|
| `j` / `k` | Wrap-aware down/up |
| `n` / `N` | Next/Previous search (centered) |
| `<C-d>` / `<C-u>` | Half page down/up (centered) |
| `J` | Join lines and keep cursor position |
| `<leader>c` | Clear search highlights |

### Buffer
| Key | Description |
|-----|-------------|
| `<leader>bn` | Next buffer |
| `<leader>bp` | Previous buffer |

### Window
| Key | Description |
|-----|-------------|
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | Move to left/bottom/top/right window |
| `<leader>sv` | Split vertically |
| `<leader>sh` | Split horizontally |
| `<C-Up>` / `<C-Down>` | Increase/decrease window height |
| `<C-Left>` / `<C-Right>` | Increase/decrease window width |

### Text Editing
| Key | Description |
|-----|-------------|
| `<A-j>` / `<A-k>` | Move line down/up |
| `v<A-j>` / `v<A-k>` | Move selection down/up |
| `v<` / `v>` | Indent left/right and reselect |

### File
| Key | Description |
|-----|-------------|
| `<leader>w` | Save file |
| `<leader>q` | Quit buffer |
| `<leader>wq` | Save and quit |
| `<leader>qq` | Force quit |
| `<leader>e` | Toggle NvimTree |
| `<leader>pa` | Copy full file path |

### Terminal
| Key | Description |
|-----|-------------|
| `<leader>t` | Toggle floating terminal |
| `<Esc>` (in terminal) | Close floating terminal |

### Diagnostics
| Key | Description |
|-----|-------------|
| `<leader>D` | Line diagnostics |
| `<leader>d` | Cursor diagnostics |
| `<leader>nd` | Next diagnostic |
| `<leader>pd` | Previous diagnostic |
| `<leader>dl` | Show line diagnostics |
| `<leader>q` | Open diagnostic list |
| `<leader>td` | Toggle diagnostics |

| `<leader>fi` | Implementations |

### FZF

### Git

### OpenCode
